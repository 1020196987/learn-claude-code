# 端点 (Endpoint)

## 定义
网络/API 术语，指服务器上"专门处理某类请求"的具体入口，是请求路径的**终点**。

## URL 结构
```
https://api.example.com/v1/messages?lang=zh
│                       │             │
└─ base URL             │             └─ 查询参数（不属于端点）
                        └─ 端点 (endpoint)
```

- **base URL** = `https://api.example.com`（服务地址）
- **endpoint** = `/v1/messages`（具体功能窗口）

## 例子
同一个 base URL `https://api.anthropic.com` 下的不同端点：

| 端点 | 用途 |
|------|------|
| `POST /v1/messages` | 发对话 |
| `POST /v1/messages/batches` | 批量对话 |
| `GET  /v1/models` | 列模型 |

## 命名来源
英文 `end`(末端) + `point`(点) = 请求的"末端接收点"，类比邮局的末端投递点。

## 实战注意
环境变量 `ANTHROPIC_BASE_URL` **只填到域名/路径前缀**（如 `https://api.minimaxi.com/anthropic`），**不要包含 `/v1/messages`**，因为 SDK 会自动拼上 endpoint。

错误示例（会重复拼路径 → 404）：
```
ANTHROPIC_BASE_URL=https://api.xxx.com/v1/messages   ❌
```
